# Grão & Aroma

Site institucional fictício desenvolvido para uma cafeteria artesanal.

O projeto foi criado como parte de uma atividade prática de desenvolvimento
front-end, envolvendo boas práticas de desenvolvimento, versionamento,
acessibilidade, responsividade, otimização e publicação em ambiente de produção.

## Funcionalidades

- Página inicial responsiva
- Seção de cardápio
- Apresentação da cafeteria
- Informações de contato
- Formulário de contato
- Menu responsivo para dispositivos móveis
- Navegação por âncoras
- Feedback de envio do formulário

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## Acessibilidade

O projeto utiliza práticas de acessibilidade baseadas nas recomendações
da WCAG 2.1.

Entre as práticas utilizadas estão:

- HTML semântico
- Labels associados aos campos de formulário
- Navegação por teclado
- Indicadores de foco visíveis
- Link para pular diretamente ao conteúdo principal
- Uso de atributos ARIA quando necessário
- Estrutura hierárquica de títulos
- Contraste entre texto e fundo
- Design responsivo

## Responsividade

O layout foi desenvolvido para funcionar em:

- computadores
- tablets
- smartphones
